# harbour-electrocosm
Electrocosm - Your EV Cosmic Horro

This app helps locate Electroverse-compatible EV charging stations across the globe, with thousands of chargers on Europe's biggest EV charging network.

Created with friendly support from Claude, who was kind enough to reverse-engineer the relevant API.

This is an early version created solely for personal use, which was never intended for public release. I'm sharing it in the hope that it might be useful to others, but please don't expect perfection.r
